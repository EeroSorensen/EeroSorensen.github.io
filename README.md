KNES 381 - Final Project: Public Portfolio (GitHub Pages) 

Eero Sorensen | University of Calgary

This repositpory contains my final project for KNES 381 at the University of Calgary. It is a public portfolio built with Github Pages using the al-folio Jekyll theme, showcasing my work completed throughout the semester. 

Site link: https://eerosorensen.github.io

## Purpose ##
This portfolio demonstrates my ability to utilize computational skills on kinesiology-related issues, including Python-based data analysis, Excel Data systems, interactive visualization, and logic-based programming

## Tools and Technology Used ##
Tool | Purpose
------------- | -------------
**Python** | Data analysis and visualization (pandas, matplotlib)
**Jupyter Notebook** | Interactive Python environment (Kaggle)
**Microsoft Excel** | PivotTable, PivotChart, slicers, conditional formatting
**Scratch** | Logic-based maze game (control flow, conditions, variables)
**Jekyll / al-folio** | Static site framework for GitHub Pages
**Markdown** | Page formatting and documentation
**Git / GitHub** | Version control and project hosting
