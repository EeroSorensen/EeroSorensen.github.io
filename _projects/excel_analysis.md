## Overview

This project analyzes an athlete performance dataset using Microsoft Excel. Demostrating core data analysis skills such as PivotTables, interactive slicers, linked charts and conditional formatting.

---

## Features
1. PivotTable | Built from performance dataset
2. Slicers | Filter the PivotTable interactively
3. PivotChart | Linked To the PicotTable
4. Conditional formatting | Rule applied to highlight key values
