## Overview ##

This project analyzes an athlete performance dataset using Microsoft Excel. Demonstrating core data analysis skills such as PivotTables, interactive slicers, linked charts and conditional formatting.

The PivotTable, serving as the core of the project, summarizes the dataset based on the selected filters. When a slicer is changed, the aggregate values are recalculated and the PivotChart will update automatically to represent the new data.

---

## How it Works ##

The dataset contains performance metrics across multiple athletes with different ages and experience levels. The flow of the data is as follows 

1. **Raw data** is entered into the spreadsheat
2. **Conditional formatting** isapplied directly to the raw data, highlights the values meeting the defined threshold, allowijng for the easy identification
3. The **PivotTable** reads the raw data and aggregates it, summarizing the metrics grouped by age and experience level
4. **Slicers** act as a filter, allowing for the selection of age and/or experience level to recalculate the PivotTable
5. The **PivotChart** represents the PivotTable data, and will automatically redraw with each PivotTable update

This process allows for the fully programmable visualization of the selected data. The selected input data and slicer filters automatically update the table and chart without manual intervention

## Features ##

Feature | Description
------------- | -------------
**PivotTable** | Built from the raw athlete performance dataset
**Slicers** | Filter the PivotTable interactively by Age and Experience Level
**PivotChart** | Linked dynamically to the PivotTable — updates with slicer selections
**Conditional Formatting** | Rule applied to the raw data to highlight key values
