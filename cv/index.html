Projects

  • VO2 Analysis — Interactive Metabolic Cart Data

    Python-based analysis of Parvo metabolic cart data from a graded exercise test. Extended from a static matplotlib figure into an interactive Plotly visualization with hover, zoom, and annotation. Dataset sourced from Kaggle (demo-knes381 by Dr. John Holash, University of Calgary).

    • 4-variable subplot figure: VO2, VE, VCO2, FECO2 vs time
    • VO2max identified and annotated at 3.72 L/min
    • Converted to interactive Plotly for portfolio embedding
  • VO2max and Training Zone Calculator

    Browser-based interactive calculator estimating VO2max from heart rate data using the Uth-Sorensen formula, with personalised training zones displayed in a dynamic chart.

    • Built in HTML and JavaScript — runs entirely in the browser
    • Outputs 5 training zones with heart rate ranges and VO2 targets
    • Interactive Plotly bar chart updates dynamically with user input
  • Scratch Maze

    Interactive maze game built in Scratch demonstrating core programming concepts including control flow, conditional logic, variables, and event-driven user interaction.

    • Arrow key controls with wall collision detection
    • Win condition triggered on maze completion
  • Excel Athlete Performance Analysis

    Data analysis of an athlete performance dataset using Microsoft Excel, featuring a PivotTable with interactive slicers, a linked PivotChart, and conditional formatting on raw data.

    • PivotTable with Age and Experience Level slicers
